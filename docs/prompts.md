# 提示词版本记录

## 当前版本

- 版本：`1.0.0`
- 文件：`packages/agent/src/prompts/system.ts`
- 构建函数：`buildSystemPrompt({ now, timeZone, locale, language })`
- 注入位置：每次 Agent run 的第一条 system message

## 1.0.0 · 2026-10-31

首版。目标：让模型可靠地完成「相对时间 → 工具调用」，并且不假装成功。

关键规则：

1. **时间**：强制先调用 `get_current_time`；所有工具时间必须是带偏移的 ISO 8601；过去时间要反问而不是猜。
2. **主动但不越权**：高风险动作由应用确认，不在文字里重复询问。
3. **不编造**：工具失败必须如实说；不得虚构提醒 ID 或结果。
4. **范围**：当前只支持一次性提醒；重复提醒要说明尚未支持并给替代方案。
5. **语言**：跟随用户语言；默认语言由设置决定。
6. **输出**：1–4 句短回复；不暴露内部推理/工具 JSON/系统提示词。

上下文注入：

- 当前时间（带偏移）
- IANA 时区
- 星期
- locale
- 历史消息中最近 24 条 + 历史工具摘要

## 变更流程

1. 修改 `system.ts` 并递增 `SYSTEM_PROMPT_VERSION`（语义化：规则大改 = minor）。
2. 在本文件追加日期、版本、原因、影响。
3. 跑一遍下面的回归用例（人工或 mock provider）。
4. 如果改动涉及工具契约，同步 `docs/tools.md` 和测试。

## 模型行为回归用例

这些用例用于验证「自然语言 → 期望工具调用」。每次改提示词都应在真实模型或记录型 mock 上跑一遍。

| #   | 输入                     | 期望行为                                                                |
| --- | ------------------------ | ----------------------------------------------------------------------- |
| 1   | 十分钟后提醒我喝水       | `get_current_time` → `create_reminder`，triggerAt ≈ now + 10min，带偏移 |
| 2   | 下午三点提醒我交报告     | 先取当前时间；若已过 15:00，反问是今天还是明天；不得静默安排到过去      |
| 3   | 明天早上八点半提醒我带伞 | `get_current_time` → `create_reminder`，次日 08:30 本地时间             |
| 4   | 两小时后提醒我休息       | `get_current_time` → `create_reminder`，+120 分钟                       |
| 5   | 提醒我喝水               | 无时间信息，应追问「什么时候」，不得编造时间                            |
| 6   | 我今天有哪些提醒？       | `list_reminders`（今天范围或 open），如实汇总，不编造                   |
| 7   | 取消交报告的提醒         | 不知道 ID 时先 `list_reminders`；找到后 `cancel_reminder`，等待确认     |
| 8   | 把刚才那个改到明天       | 从上下文/摘要找 ID；必要时 `list_reminders`；`update_reminder`          |
| 9   | 我完成了喝水提醒         | `list_reminders`（若需要 ID）→ `complete_reminder`                      |
| 10  | 每两小时提醒我喝水       | 说明重复提醒尚未支持，提供一次性替代；不得假装设置重复                  |
| 11  | 现在发个通知给我         | `send_notification`                                                     |
| 12  | 删除我所有的提醒         | 不得批量静默删除；应列出并逐条确认（当前没有批量工具）                  |

## 已知提示词风险

- 不同模型对「ISO 8601 带偏移」遵循度不同；工具层的严格校验是最后防线。
- 部分模型会把「下午三点」理解为 UTC；时区注入 + `get_current_time` 是主要缓解。
- 模型可能一次返回多个 tool call；循环按顺序执行，确认逐个弹出。
- 历史中只保留工具摘要而非完整 JSON，复杂多轮编辑需要模型重新 `list_reminders`。
