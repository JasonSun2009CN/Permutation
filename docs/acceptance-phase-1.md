## 3. 端到端冒烟（mock LLM）

目的：在不消耗真实 token 的情况下验证 Electron 主进程、IPC、Agent、工具、SQLite、调度器、UI 事件。

步骤：

1. 用 `scripts/seed-demo.ts` 生成临时数据库，设置 Base URL 为 `http://127.0.0.1:8787/v1`。
2. 启动 `scripts/mock-llm.mjs`（返回 `get_current_time` → `create_reminder` → 最终文本）。
3. 以 `PERMUTATION_USER_DATA_DIR` 指向临时目录启动应用，注入 `PERMUTATION_API_KEY`（仅未打包模式）。
4. 自动输入「一分钟后提醒我喝水」并发送。
5. 等待调度器触发，截图。

观察结果：

- 用户消息、两次工具调用（读取当前时间、创建提醒）、最终回复均正确显示。
- 数据库新增 `reminders` 记录，`trigger_at` 为 UTC ISO，初始 `status=pending`。
- 到点后 `status=fired`，`fired_at` 写入；应用内提醒卡片出现，含「完成 / 推迟 10 分钟 / 忽略」。
- 实测触发时间比设定晚约 11 秒（15 秒 tick 的正常范围）。
